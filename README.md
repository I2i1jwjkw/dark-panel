# Dark Panel

رابط کاربری اولیه برای پنل مدیریت VPN با طراحی تیره و راست‌چین.

## اجرا
فایل `index.html` را در مرورگر باز کنید. برای انتشار می‌توانید GitHub Pages را در تنظیمات مخزن فعال کنید.

## امکانات نسخه اولیه
- داشبورد آماری نمونه
- فهرست و جستجوی کاربران
- افزودن کاربر آزمایشی در همان صفحه
- صفحات سرورها، ترافیک و تنظیمات
- طراحی واکنش‌گرا برای موبایل و دسکتاپ

## وضعیت
این نسخه فقط یک نمونه رابط کاربری (frontend prototype) است. اطلاعات کاربران و آمار ساختگی‌اند و افزودن کاربر فقط در حافظه همان صفحه انجام می‌شود. هنوز به سرور VPN، Xray، دیتابیس یا API متصل نیست و برای استفاده عملیاتی آماده نیست.

## گام‌های بعدی
1. انتخاب بک‌اند و روش احراز هویت
2. اتصال امن به API سرورهای VPN
3. ذخیره‌سازی کاربران و اشتراک‌ها
4. اعمال محدودیت حجم و تاریخ انقضا در سمت سرور
5. افزودن مدیریت دسترسی و ثبت رویدادها

**امنیت:** کلیدهای API و رمزهای سرور را داخل کد فرانت‌اند قرار ندهید.
